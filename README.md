# AWS 101 sign-ups

The sign-up app for the AWS Student Builder Group's AWS 101: Core Services Workshop (October 7, 2026). One Next.js app: a public waitlist page at `/` and an organizer table at `/admin`.

**Attending the workshop? Follow [WORKSHOP.md](WORKSHOP.md).**

## Run it

Node.js 20.9 or later:

```bash
npm install
npm run build
npm start
```

Open http://localhost:3000. On EC2, use a **t3.small** or larger (the build needs about 1.3 GB of memory) and allow port 3000 in the security group, ideally from **My IP** only.

## Where sign-ups are stored

| `.env` | Storage | `/admin` label |
|---|---|---|
| nothing | `signups.json` in this folder | Local JSON |
| `DATABASE_URL=postgres://user:pass@host:5432/db` | that PostgreSQL database (table created on first use) | RDS PostgreSQL, or PostgreSQL for other hosts |

Change `.env`, then restart with `npm start`; no rebuild needed. Connections to `*.rds.amazonaws.com` use TLS and verify the server with Amazon's public RDS certificate bundle in `certs/`.

`/admin` has no login: this is a workshop app. Use test data, and keep the security group limited to your own IP.

## Project layout

```
src/app/page.js          waitlist page (/): shows a count and initials, never emails
src/app/admin/page.js    organizer table (/admin)
src/app/actions.js       add and delete, with validation (Next.js server actions)
src/lib/storage.js       JSON file or PostgreSQL, picked by DATABASE_URL
src/components/          UI (shadcn/ui, Motion); ui/ is generated by shadcn
certs/                   Amazon's public RDS certificate bundle
deploy/nginx.conf        reverse proxy used by compose.yaml
test/                    npm test
```

## Run it behind nginx (Docker)

nginx listens on port 80 and forwards to the app, which is not exposed directly.

```bash
docker compose up --build -d
```

On EC2, install Docker and the compose plugin first:

```bash
sudo dnf install -y docker git
sudo systemctl enable --now docker
sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo curl -SL "https://github.com/docker/compose/releases/latest/download/docker-compose-linux-$(uname -m)" \
  -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
```

Allow **HTTP 80** in the security group. Put `DATABASE_URL` in `.env` next to `compose.yaml` to use RDS. On a laptop where port 80 is taken: `AWS_SBG_PORT=8080 docker compose up --build`.

## Tests

```bash
npm test
```

Covers the JSON store and labels. To also test PostgreSQL, start one and pass its URL:

```bash
docker run -d --rm --name pg -e POSTGRES_PASSWORD=pw -p 55432:5432 postgres:17-alpine
TEST_DATABASE_URL=postgres://postgres:pw@localhost:55432/postgres npm test
```
